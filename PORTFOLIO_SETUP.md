# Eklmn Digital — личное портфолио (черновик)

Основа: проект Grok, переработанный в личное портфолио.

## Перед публикацией
1. Указать собственный контактный email в `src/components/folio/letter.tsx` и `colophon.tsx` вместо CONTACT_EMAIL_HERE.
2. Указать `VITE_CONTACT_EMAIL` в `.env.local` (см. `.env.example`), иначе форма работает в DEMO-режиме. Она использует mailto и не отправляет сообщения самостоятельно.
3. Проверить лицензию на изображения, заменить чужие/демонстрационные фотографии при необходимости.
4. Запустить `npm ci`, `npm run typecheck`, `npm run build:dev` и проверить мобильную версию.
5. Не выдавать демонстрационные проекты за выполненные заказы.

## Статус
Это черновик исходников, не опубликованный и не подтверждённый как рабочий сайт.
