# Коммерческий шаблон — версия 0.1

Основа: экспорт Grok, сохранён оригинальный журнальный дизайн.

## Изменения
- Форма больше не имитирует успешную отправку.
- При наличии `VITE_CONTACT_EMAIL` создаётся письмо через `mailto:` (пользователь должен подтвердить отправку в почтовом приложении).
- Без адреса показывается явное сообщение о демонстрационном режиме.

## Настройка
1. Скопируйте `.env.example` в `.env.local`.
2. Укажите свой email вместо `your-email@example.com`.
3. Установите зависимости: `npm install`.
4. Запустите `npm run dev` или соберите `npm run build:dev`.

## Перед продажей/публикацией
- Заменить вымышленные имя, почту, город и восемь демонстрационных проектов.
- Получить разрешения на использование изображений и проверить лицензии.
- Проверить сборку и работу на Android и компьютере.
- Для реальной серверной отправки подключить отдельный почтовый сервис и защиту от спама.

Сборка в этой среде не проверялась.
